> 작성일: 2026-06-06 | 브랜치: cksung9009-mainbranch | 모호도: 15.2% (임계값 20% 이하 달성)

---

## 제품 목표

법령이 개정될 때, 영향받는 사내 규정을 **하나도 빠뜨리지 않고** 자동으로 탐지하고, AI가 신구조문대비표와 판례 근거를 포함한 개정안 초안을 생성해 **여러 부서 내부 규정 전담 담당자의 수작업을 최소화**한다.

- **단기 집중 영역**: 노동법 (근로기준법, 최저임금법, 산업안전보건법 등) — 프로젝트 발표 기준
- **장기 목표**: 전 산업 범용 확장

---

## 주요 사용자

여러 부서에 걸친 사내 규정을 전담하는 컴플라이언스/준법 담당자

---

## 기능 구성

### 핵심 기능 (주간 사용 루틴)

#### 1-A. 법령 개정 디텍팅 (스캔 모드)
- **입력**: 개정된 법령 내용
- **출력**: 영향받는 사내 규정 리스트 + 규정별 개정 필요 사유 + 해당 법령 조항(법적 근거)
- **현황**: 구현됨 (`src/ai/flows/detect-law-impact-flow.ts`)

#### 1-B. 개정안 자동 생성 + 판례 검증
- **입력**: 1-A 스캔 결과 (영향받는 규정)
- **출력**:
  - 개정 사유 및 주요 골자
  - 신구조문대비표 (Before / After 비교)
  - 판례 교차검증 리포트 (관련 판례 논거 제시 + 기존 판례 충돌 여부)
- **현황**: 개정안 생성 부분 구현됨 (`src/ai/flows/generate-regulation-draft-flow.ts`) / **판례 검증 미구현**

### 부수 기능 (월간 단위 사용)

#### 4. 경영 방향성 기반 전사 규정 일괄 정렬
- **입력**: 미리 정의된 경영 정책 커미트먼트 선택 (ESG, 다양성, 안전 우선 등)
- **출력**: 관련 전사 규정 일괄 개정안 + 신구조문대비표
- **현황**: 미구현

#### 5. 내부 규정 간 충돌 탐지
- **탐지 범위**:
  - 직접 논리 충돌 (예: A규정 "스톡옵션 부여" ↔ B규정 "스톡옵션 금지")
  - 수치 비일관성 (예: A규정 "휴가 15일" ↔ B규정 "휴가 20일")
  - 의미 중복 (다른 표현으로 동일한 내용)
- **출력**: 충돌 지점 + 중재안
- **현황**: 미구현

#### 6. 내/외부 통합 컴플라이언스 챗봇
- **데이터 소스**: 사내 규정 + law.go.kr 판례 데이터 (MCP 연동)
- **출력**: 규정·판례를 근거로 한 실시간 행동 가이드
- **현황**: 챗봇 기본 구현됨 (`src/ai/flows/answer-compliance-question.ts`) / **판례 연동 미구현**

### 연기된 기능

#### 1-C. 연쇄 영향 탐지 (도미노 체크)
- **내용**: 개정된 규정으로 인해 추가로 수정이 필요한 다른 규정 탐지
- **상태**: 추후 개발 예정

## 제약 사항

- **데이터 저장**: 브라우저 메모리 전용 (세션 종료 시 삭제, Firestore 미사용)
- **판례 데이터**: 국가법령정보센터 law.go.kr MCP 연동 — **현재 미구현, 구현 필요**
- **법적 책임**: AI 생성 초안은 반드시 담당자 검토 후 사용 (법적 자문 아님)
- **기술 스택**: Next.js 15 (App Router), Genkit + Gemini 2.5 Flash, TypeScript

## 제외 범위

- 1-C 연쇄 영향 탐지 (추후 개발)
- 외부 기관(고용노동부, 금감원 등)과의 직접 채널 연결
- 법원 판결문 실시간 스트리밍 (law.go.kr API 범위 내에서만)
- 법적 자문 기능 (AI 출력은 초안, 최종 판단은 사람)
- 노동법 외 영역 (단기 발표 기준 — 장기는 범용 확장 예정)
