# RegulMate (formerly mentalcoach)

> 🚀 **데모 배포**: https://regulmate.vercel.app

이 프로젝트는 mentalcoach(마음코치)에서 **RegulMate(레귤메이트)** 로 피봇되었습니다.

## 📌 현재 진행 상황
- 팀원 각자 브랜치에서 [MANIFESTO](./MANIFESTO.md) 기반으로 개발 진행
- **데모데이 및 사용자 피드백 반영하여 추가 개발 반영**

## 새로운 방향
- **RegulMate**: 사내 규정 컴플라이언스 자동화 SaaS
- 법령 개정 모니터링 → 사내 규정 영향 분석 → 개정안 초안 작성까지의 컴플라이언스 프로세스를 End-to-End 자동화
- **타겟 고객**: 컴플라이언스 의무는 있으나 전담 인력이 부족한 스타트업·중소·중견기업 규정 담당팀 (필요시 인사·노무, 안전 등으로 분야 세분화)

## 핵심 기능 (MVP)
| 기능 | 설명 |
|---|---|
| 📡 법령 개정 디텍팅 | 법령 개정 감지 → 영향받는 사내 규정 + 개정 필요 사유/법적 근거 자동 추출 |
| 📝 개정안 자동 생성 | 선택한 규정의 개정 사유 / 신구조문대비표 / 판례 교차검증 리포트 생성 |
| 🤖 컴플라이언스 챗봇 | 규정 + 판례를 엮은 실시간 행동 가이드 응답 |

## ✨ 데모데이·피드백 반영 추가 개선 (vs 초기 버전)

**1. AI 환각 방지 — 국가법령정보센터 실시간 연동(MCP)**
- 스캔·개정안 생성 시 AI가 실제 법령 본문을 실시간 조회 → 최신 법령 기반으로 작성 (법 개정 시 자동 반영)
- 법령 본문을 조문·항·호 단위로 정확히 파싱, 조항 간 참조(예: 제4항→제2항) 추적
- AI가 조문을 원문 그대로 인용하도록 강제 (항번호 혼동·단서 누락 방지)

**2. 자동 검증 레이어 — 코드가 AI 답변을 실제 법령과 재대조**
- AI 인용을 실제 법령 본문과 기계적으로 대조해 결과를 4단계로 표기
  - ✅ 통과 / ⚠️ 원문 재확인 필요(환각·단서누락) / ℹ️ 자동검증 미수행 / (검증 대상 외)
- 환각(없는 수치 인용)·단서 누락(예: "다만 6개월 추가" 생략)을 자동 검출

**3. 분석 품질·신뢰성 강화**
- 영향도(즉시개정/검토) 판정 기준 객관화 (법정 숫자 미달 → 즉시개정)
- 한 규정의 여러 변경점을 빠짐없이 추출 (예: 휴가일수 + 분할횟수 동시)
- 법령 서버 일시 끊김 자동 재시도, 모델 gemini-2.5-pro 적용

**4. 사용성·기타**
- AI 결과물 면책 안내 팝업 (스캔·개정안 완료 시)
- 개정안 결과 Word(.docx) 내보내기
- 스캔 → 개정안 이동 시 대상 규정 자동 선택
- 법령 영향 스캔 UI 정리 (AI 법령 스캔 버튼 중심)
- 스캔 저장 로직 회귀 테스트 추가

## 기술 스택
- **Frontend/Backend**: Next.js 15, TypeScript
- **AI**: Google Genkit + Gemini, 국가법령정보센터 연동(Korea Law MCP)
- **DB/Auth**: Firebase (Firestore)
- **배포**: Vercel
