## 목표

법령이 개정될 때, 영향받는 사내 규정을 **하나도 빠뜨리지 않고** 자동으로 탐지하고, AI가 신구조문대비표와 판례 근거를 포함한 개정안 초안을 생성해 **여러 부서 내부 규정 전담 담당자의 수작업을 최소화**한다.

단기 집중 영역: **노동법** (근로기준법, 최저임금법, 산업안전보건법 등)
장기 목표: 전 산업 범용 확장

---

## 제약 사항

- **사용자**: 여러 부서에 걸친 사내 규정을 전담하는 컴플라이언스/준법 담당자
- **판례 데이터**: 국가법령정보센터(law.go.kr) MCP 연동 — 현재 미구현, 구현 필요
- **데이터 저장**: 브라우저 메모리 전용 (Firestore 제거된 상태, 세션 종료 시 삭제)
- **기술 스택**: Next.js 15 (App Router), Genkit + Gemini 2.5 Flash, TypeScript
- **현재 스코프**: 노동법 포커스 (프로젝트 발표 기준)
- **법적 책임**: AI 생성 초안은 반드시 담당자 검토 후 사용 (법적 자문 아님)

## 인수 기준 (Acceptance Criteria)

### 핵심 기준 (1-A + 1-B)

- [ ] 특정 법령 개정안 입력 시, 영향받는 사내 규정을 **누락 없이 (0% 누락률)** 식별한다
- [ ] 각 규정별로 개정이 필요한 사유와 해당 법령 조항을 함께 출력한다
- [ ] 1-B: 영향받는 규정에 대해 신구조문대비표 형식의 개정안 초안을 생성한다
- [ ] 1-B: 개정안과 관련된 판례를 검색해 논거로 제시한다 (law.go.kr MCP)
- [ ] 1-B: 개정안이 기존 판례와 충돌하는 경우 충돌 지점을 명시한다
- [ ] 판례 검증 리포트는 관련 판례 + 충돌 여부 + 법적 근거를 포함한다

### 부수 기준

- [ ] 4번: 미리 정의된 경영 정책 커미트먼트(ESG, 다양성, 안전 우선 등) 중 선택하면 관련 사내 규정 전체에 일괄 개정안을 생성한다
- [ ] 5번: 사내 규정 간 직접 논리 충돌, 수치 비일관성, 의미 중복을 탐지하고 충돌 위치와 중재안을 제시한다
- [ ] 6번: 담당자가 규정 관련 질문을 입력하면 사내 규정 + law.go.kr 판례를 바탕으로 답변한다

### 부수 성공 지표 (측정 목표, 필수 아님)

- 개정안 작성 소요 시간 단축
- AI 초안에 대한 법무팀의 대규모 수정 없는 승인 비율 향상
